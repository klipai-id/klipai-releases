# KlipAI

Tempel link, panen klip. Video YouTube panjang jadi klip 9:16 siap posting, diproses di komputer kamu sendiri.

Website: https://klipai.id

## Download versi terbaru

- **Mac** (Apple Silicon M1 ke atas, macOS 13+): [KlipAI-Mac.dmg](https://github.com/klipai-id/klipai-releases/releases/latest/download/KlipAI-Mac.dmg)
- **Windows** (10/11 64-bit): [KlipAI-Windows-Setup.exe](https://github.com/klipai-id/klipai-releases/releases/latest/download/KlipAI-Windows-Setup.exe)

Semua versi: [Releases](https://github.com/klipai-id/klipai-releases/releases)

## Pertama kali dibuka

- **Mac:** seret KlipAI ke Applications, lalu klik kanan KlipAI → Buka → Buka.
- **Windows:** kalau muncul "Windows protected your PC", klik More info → Run anyway.

Bantuan: support@klipai.id
